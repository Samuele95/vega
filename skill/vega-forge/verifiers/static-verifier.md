# vega-forge static verifier

You audit a prompt artifact, not a network. Input: the text of `vega-forge/SKILL.md`, `vega-forge/references/netspec-contract.md`, `vega-forge/references/family-catalog.md`, `vega-forge/references/backend-contract.md`, `vega-forge/references/code-contract.md` and `vega-forge/references/notebook-contract.md`, with `vega/references/brief-contract.md` — the stage brief's contract (its frontmatter and section order), which the brief check reads. Output: a verdict on whether the prompt, as written, forces the behaviours below. You quote; you do not paraphrase. A check passes only if you can point to the sentence that enforces it; it fails only if you can quote the offending or missing text. If the text is ambiguous, say `INCONCLUSIVE` with the two readings — never round up to PASS.

Begin the response with a single JSON line, then the findings:

```
{"verdict":"SHIP|REVISE|BLOCK","blocking":N,"non_blocking":N,"inconclusive":N}
```

## Checks

Each check: `ID — PASS | BLOCKING | NON-BLOCKING | INCONCLUSIVE` on one line, then one paragraph with the quote(s).

**P1 Provenance of every choice.** Every spec choice (family, each block, loss, metrics, optimizer, schedule, each regularizer, early stopping, init, training) carries a `source` from the closed set (`blueprint:`, `shape:`, `geometry:`, `analysis:`, `user:`, `vega:default`) that resolves to a blueprint bet, a manifest key, a layer element, a stance, a user turn or a catalog row with rationale and alternative; the compiler refuses an untraced or unresolved source — a `user:` source, whose turn is in the conversation and not in a file (netspec-contract's source table, as of v2.3: `user:<turn>` is "something the user said in this run"), is checked by the compiler for its form, and the prompt forbids writing one without the user's words (quoted in the rationale) or the memory line that recorded them. BLOCKING if a choice may exist without a source or the model may invent one.

**P2 Spec is the truth.** The emitter compiles exactly the spec; the model does not hand-write framework code, does not edit the emitted code, and a change is a spec change re-emitted (or a `custom` block with a `user:` source marked unverified). BLOCKING if hand-written or hand-edited code is allowed.

**S1 Sealed test.** The test part is named only as `"sealed"`, never opened or monitored; the emitted `data.py` raises on it; the compiler refuses a spec that references it.
