# vega-train static verifier

You audit a prompt artifact, not a training run. Input: the text of `vega-train/SKILL.md`, `vega-train/references/run-contract.md` and `vega-train/references/training-catalog.md`, with `vega/references/brief-contract.md` — the stage brief's contract (its frontmatter and section order), which the brief check reads. Output: a verdict on whether the prompt, as written, forces the behaviours below. You quote; you do not paraphrase. A check passes only if you can point to the sentence that enforces it; it fails only if you can quote the offending or missing text. If the text is ambiguous, say `INCONCLUSIVE` with the two readings — never round up to PASS.

Begin the response with a single JSON line, then the findings:

```
{"verdict":"SHIP|REVISE|BLOCK","blocking":N,"non_blocking":N,"inconclusive":N}
```

## Checks

Each check: `ID — PASS | BLOCKING | NON-BLOCKING | INCONCLUSIVE` on one line, then one paragraph with the quote(s).

**H1 Hypothesis before run.** Every run is a rung of `ladder.json` with `hypothesis`, `source` (closed set: `netspec`, `netspec:<path>`, `vega:ladder/<rule>`, `train:diagnostic/<code>`, `train:hpo/<study>`, `analysis:`, `user:`), a `delta` that recompiles, and an `expect` whose outcome the ledger records; an ablation changes one thing. BLOCKING if a run may exist without a hypothesis or a source, or if a multi-change ablation is allowed.

**S1 Sealed test.** The trainer never opens the test part (`data.py` raises), never selects or diagnoses on it; a campaign with `test_seal.json` present refuses to start without `--after-eval`, which is recorded. The one exception is the forge's declared `transductive` graph protocol (the plan's R-A10: supported through train and eval, refused at pack) (a `user:` source and a disclosed `exposure`): the test nodes' feature columns — never their labels — are part of the training graph, read through the data adapter's one named door, and the layer discloses it. BLOCKING if the test labels may be touched, or the test features outside that declared, disclosed exception.

**L1 Ledger is the truth.** `netspec.json` and the emitted code are never edited in place; deltas are applied by the trainer and recorded; runs are append-only; readings cite `history.jsonl` / `experiments.json`, and numbers are never retyped. BLOCKING if in-place edits or unrecorded runs are allowed.

**R1 Selection rule before result.** The selection rule (with source and alternative) is stated at planning, applied mechanically, eligibility is mechanical (D1, D2, D9-before-improvement), an ineligible run is selectable only by a `user:` choice with a reason; the apply script refuses an ineligible selection. BLOCKING if the rule may be chosen after seeing the ledger or an ineligible run may be selected by rule.

**D1 Diagnostics mechanical, readings the model's.** Each diagnostic is a condition on the records with evidence; the reading is the skill's; a diagnostic's rung is a proposal (fork attended; first two run unattended within budget). NON-BLOCKING if a diagnostic lacks a mechanical condition; BLOCKING if a diagnostic may override a stance.

**F1 Forks and the unattended floor.** The ladder is one `FORK:` attended, the selection the last; unattended, the default ladder and rule apply and are marked; `--ladder` still gates `vega:ladder/…` rungs; `--emit-only` ends in a `GATE:`. BLOCKING if either branch is missing or unattended may ask.

**B1 Budget honesty.** A run stopped by budget is D9, never a result; the campaign stops at its wall clock; an unconverged baseline stops the campaign and says so. NON-BLOCKING if the D9 reading is optional; BLOCKING if a budget-cut run may be read as a result.

**E1 Remote execution integrity.** `--import-run` verifies spec, code and part digests and the record schema; a mismatch is `ERROR:`. BLOCKING if an imported campaign may be accepted unverified.

**N1 Notebook replay.** `train.ipynb` is generated by `nb_emit.py`, executed, and replays the selected run's first epochs against `history.jsonl` within the backend's tolerance; a replay mismatch is `ERROR:` before publishing; an unexecuted notebook is a `WARN:`. BLOCKING if the replay is optional.

**V1 Layer validation.** `apply_training_layer.py` (through `domain-forge/scripts/apply_layer.py`) refuses an ineligible selection or a failed replay; `validate_model.py` exit 0 (13–16) and `smoke_training.py --strict` with the no-browser degradation stated; histories downsampled with the full file named. BLOCKING if optional.

**S2 Single source of truth.** Renderer a shipped asset; the spec, backend, notebook and analysis contracts read from their owners, not restated; `compile_spec.py` and `emit_backend.py` reused, not reimplemented. BLOCKING on a private writer or per-run JS; NON-BLOCKING for small restatements.

**C1 Catalog completeness.** Every ladder rule, diagnostic code and search space the SKILL.md or contract names appears in the training catalog with its row. NON-BLOCKING per missing entry.

**U1 Published before summarised (package check).** The prompt has a *Publish the artifact* step after validation and the smoke test and before memory and the summary: the layered HTML is opened in the conversation (artifact/file tool, else delivered inline), the new *Training* tab named in one line, a file that failed validation or smoke is not published, and "there is no summary of an unpublished stage"; the summary opens with the published artifact; a failure-mode bullet forbids summarising an unpublished stage. BLOCKING if the summary may run without the publish step; NON-BLOCKING if the step exists but the summary's first line is not the artifact.

**U2 Stage brief (package check).** The prompt has a *Write the stage brief* step producing `<dir>/docs/train-brief.md` per `vega/references/brief-contract.md`, after publish and before the summary, naming the frontmatter's `records`, the seven sections in the contract's order, and the rule "every number with its record key, nothing the layer does not hold"; the done-when requires it; the summary names its path and offers `/document-project vega <lane> train` guarded by LaTeX and the skill's presence. BLOCKING if the brief may be skipped or written before the layer verified; NON-BLOCKING if a section name differs from the contract.

**U3 Orchestrator named.** "Where this skill sits" names `/vega` (not `/noctua`) as the scheduler and says it checks the publish and the brief; the four network stages, where the prompt names them, are the "network sub-chain" of the Vega package (never "the Vega sub-chain"). NON-BLOCKING per stale name, quoted.

**D2 Early stopping on noise is a diagnostic.** The catalog has a mechanical rule (D13) that fires when early stopping stopped a run while the learning rate was still near its peak and the valid primary's slope was positive beyond its noise band, proposes a patience rung run before the ablations are read, and says a ladder whose baseline fired it is re-based. BLOCKING if absent (every ablation would be read at an under-trained baseline); NON-BLOCKING if the thresholds are unstated.

**CM1 Coverage matrix.** The contract makes the backend coverage matrix the evidence that this stage covers every admitted cell: `vega-forge/scripts/tests/matrix/run_matrix.py --cells all` fits each cell through the adapters this stage drives (`PackageAdapters` → `Network.build` → `Trainer().fit(…, run=RunContext(…))`, the checkpoint through the ModelStore) for every cell of `vega-forge/scripts/catalog.json`'s admission table, and a change to this stage ships only when the report (`vega/backend-matrix@1`) is green (`summary.failed == []`) and its cell list equals the admission table (`admission.table: "equal"`) — `run-contract.md` §8; a cell admitted and not run is a defect, never a skip. BLOCKING if the prompt claims a case outside the admission table as covered; NON-BLOCKING if the green-and-equal obligation is missing.

**M1 Markers.** `OK:`/`WARN:`/`ERROR:`/`FORK:`/`GATE:` before prose. NON-BLOCKING if optional.

**M2 Memory.** Reads Network and Analysis stances before planning; writes the ladder and the selection after; a declined rung is not planned. NON-BLOCKING if read-only; BLOCKING if stances may be overridden silently.

**P1 Blueprint protocol.** The blueprint's `training.protocol` is followed or overridden with `train:protocol-override` and a reason recorded in `campaign.json`; re-emitted code passes the mechanical conformance check. NON-BLOCKING if the override may go unrecorded; BLOCKING if re-emitted code may skip the check.

**X1 Data untouched.** No resampling, re-splitting or re-encoding to make a run work; D10 records a data issue as an open item for the shaper. BLOCKING if the trainer may reshape the data.

**R2 Reasoning-channel separation.** No "show your thinking"-class instruction. BLOCKING if present.

**A1 Right altitude.** Sample three directives; each specific enough to act on and general enough for a family and a budget the author did not foresee. NON-BLOCKING per brittle or vague directive, quoted.

**H2 Hand-off.** The summary names `/vega-eval` on the selected run, states the test is unopened, and lists open items. NON-BLOCKING if missing.

## Verdict rule

`BLOCK` if any BLOCKING. `REVISE` if ≥3 NON-BLOCKING or ≥1 INCONCLUSIVE on H1, S1, L1, R1, N1, V1. Otherwise `SHIP`. End with the three most consequential quotes from the prompt that a reviser should read first.
