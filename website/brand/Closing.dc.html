04 · THE INTERACTIVE FIGURES

The ground

Teaches: the star is a network — stars are units, faint lines are weights, light travels. Rest: a still composition. Pauses off-screen and on hidden tabs; still under reduced motion.

The chain

Teaches: ten stages, what each hands on, /vega checking each product. Rest: every star named and grouped, every hand-off drawn, and all ten written out below. Reduced motion: the light along the chain stops.

The rules

Teaches: which stages carry a rule and which guarantees each one holds up. Rest: all six rules, each with its guarantees written beside it; all seven guarantee cards.

Coverage

Teaches: exactly which family × shape × task cells exist. Rest: all 124 stars, the 3 variant rings and the 5 screenshot rings in one chart; filters only highlight. Each cell's title carries its status for keyboard and screen readers.

Install

Teaches: the order of the five steps. Rest: every step and command written out; ticks and copy buttons add convenience, not information.

05 · THE MARK, AND LIBRARIES

On a 64-unit grid: two tapered diamonds are the diffraction spikes (vertical 54 units, horizontal 46); four tip units (r 2.8) end them, so every spike is a connection; four diagonal units (r 2) on 1-unit lines are a second layer; the core is r 5.2. The 32 px icon drops the diagonal lines and thickens the spikes, so the network reading rests on eight units around one core, not on hairlines. Wordmark: 1.7-unit monoline, 20-unit cap height, wide tracking; the A carries a unit where its crossbar would be.

No library is vendored. The ground is hand-written canvas (assets/vega-ground.js, ~8 KB); every figure is HTML and SVG.

06 · TACTICAL DECISIONS

  1. Threshold tagline: candidate 1; three of my own offered at S1.
  2. System fonts instead of a bundled webfont: nothing to host, nothing remote.
  3. The threshold keeps the ground you approved; inner pages share it at a quiet level.
  4. Screenshot → cell: both MLP screenshots as row · mlp-plain (multiclass, regression); GRU forecast as window · gru · forecast; bi-GRU as window · bi-gru · sequence-classification/multiclass (its task is not visible — least certain); GAT as graph (node level) · gat · multiclass.
  5. panel-network-detail is a side-by-side; only its left half is shown.
  6. Guarantees tied to the stage that stages.md says produces them; dataset-shaper and vega-train carry a rule but no card.
  7. Install steps 1–2 show the folder names only — the pack gives no shell command, so none was written.
  8. Docs: content in docs/stages.js; a page is one line. Enumerating sentences shown as lists.
  9. Keyboard: ↵ / → enter, n / p next / previous, 0–4 jump, i index, t theme, esc close. Theme and install ticks remembered in localStorage.
  10. Banners: all text inside 40 px; on X and LinkedIn inside the central 1100 px.

07 · OPEN ITEMS
